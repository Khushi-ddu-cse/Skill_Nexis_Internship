# Skill Nexis — Week 1 Final Pack

This ZIP contains the three Week 1 deliverables in separate folders:

1. `1_Assignment_1_Personal_Portfolio` — HTML, CSS, JavaScript portfolio website.
2. `2_Assignment_2_React_Components` — React practice for components, props, state, and forms.
3. `3_Mini_Project_React_Blog_UI` — React blog UI mini project with search and category filters.

## Which folder needs Node.js?
- Assignment 1: No Node.js needed. Open `index.html` in a browser.
- Assignment 2: Node.js needed. Open that folder in a terminal, run `npm install`, then `npm run dev`.
- Mini Project: Node.js needed. Open that folder in a terminal, run `npm install`, then `npm run dev`.

Run `npm install` separately inside each React folder because each is a separate project.

## Before submission
- Replace the sample portfolio details with your own accurate information.
- Run and test both React folders.
- Take screenshots of the working pages if your internship portal asks for proof.
- Read the README inside each folder.
- Make sure you can explain the code; these projects are designed for practice and learning.
