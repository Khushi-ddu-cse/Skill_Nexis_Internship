# Mini Project — React Blog UI

A beginner-friendly blog interface built with React and local JSON data.

## Features
- Blog cards generated from `src/blogs.json`
- Search by article title, excerpt, or category
- Filter by Technology, Lifestyle, Creativity, and Travel
- Article preview modal
- Responsive design for mobile and desktop
- Empty state and clear-filters action

## Run
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL displayed in the terminal.

## Important
This is a frontend mini project. It does not include user login, a backend API, or a database. Blog data is read from the local JSON file.
