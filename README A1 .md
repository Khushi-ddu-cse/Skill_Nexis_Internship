# Assignment 1 — Personal Portfolio Website

## Files
- `index.html` — page structure and sections
- `style.css` — layout, colours, and responsive design
- `script.js` — contact form validation

## Run
Open `index.html` in your browser. No installation is required.

## Practice checklist
- [ ] Open each navigation link.
- [ ] Resize the browser to check the responsive layout.
- [ ] Submit the form with an empty field.
- [ ] Try an invalid email, then a valid email.
- [ ] Replace the sample name, education, and projects with your own details.

Note: The contact form demonstrates client-side validation only. It does not send or store messages.
